# ReplicantTag · 用户标记器

[![GreasyFork 安装](https://img.shields.io/badge/GreasyFork-安装-e4572e?logo=greasyfork)](https://greasyfork.org/zh-CN/scripts/599393) [![GitHub](https://img.shields.io/badge/GitHub-源码-181717?logo=github)](https://github.com/saiyajiang/ReplicantTag) ![License](https://img.shields.io/badge/license-MIT-green)

给**视频或评论对应的用户**打标记：自动记录昵称与 UID，并把当时的上下文一并留痕。标记可下拉复用，一个用户可有多个标记，标记直接显示在页面上，支持隐身模式与 JSON 备份。

> 本脚本**由 AI 编写**，作者 [saiyajiang](https://github.com/saiyajiang)。

当前支持站点：**哔哩哔哩（bilibili.com）**——视频播放页、用户空间页、视频卡片、评论区。架构按多站点预留，后续将扩展至更多站点。

## 关于「给人打标签」

**给人贴标签本身就是一种不好的行为。** 它把一个立体的人压成几个扁平的词，一次误判就可能长期影响你对这个人的判断；它容易滑向偏见、歧视与网暴，也容易让你在还没看清一个人的时候就先给他判了刑。如果你要使用这类工具，请尽量只描述**可观察到的事实与行为**，不要对真实的人做价值评判、人身攻击，也不要归档敏感个人信息。

**但网络上确实存在大量无法被定义的人。** 营销号、搬运号、机器人、水军、反复出现的抬杠账号、批量生产的模板评论……它们没有人格的复杂性，行为高度扁平化、模式化，日复一日重复同一套动作，更像一个个 NPC 而不是人。面对这类账号，每一次都重新辨认的成本极高，而它们消耗的却是你真实的注意力。

**所以有的时候，我们不得不对这些「NPC」做标记管理。** 这不是在给人贴标签，而是在给自己做信息环境的卫生——把重复出现的模式识别出来，一次记住，之后就不再为它付费注意力。

本脚本只是一个**本地记录工具**：数据保存在你自己的浏览器里，不联网、不上传、不共享。它不替你判断谁是人、谁是 NPC，如何使用它，取决于你。

## 功能

### 留痕内容

| 场景 | 自动记录 |
|---|---|
| 视频 / 动态卡片 | 昵称、UID、**视频标题**、**BV 号**、**视频时间** |
| 评论 | 昵称、UID、**评论正文** |
| 用户空间页 | 昵称、UID、空间页链接 |
| 全部 | 标记时间、来源页面 URL |

- 一个用户可累积多条留痕（每用户上限 50 条）
- 留痕列表可直接跳转对应视频/个人空间

### 标记管理

- **标记可复用**：输入框聚焦即弹出历史标记库下拉，支持模糊过滤，点击即填
- **一个用户多个标记**：输入 `搬运, 广告号`，逗号/分号/竖线分隔即可一次打多个
- 标记可单独删除，用户可整体删除

### 页面内显示

标记以**浮层（overlay）**方式渲染，**不向页面插入任何节点**——这是刻意的设计：B 站评论区由 Lit 框架渲染，向其 shadow DOM 内插入外部节点会破坏 DOM 协调，导致整块评论区卸载白屏。浮层方案彻底避免该问题，也不会撑开页面布局。

- 评论区：标记显示在**评论行右侧空白区**（与等级徽章同一水平线），不再紧贴头像挤在一起
- 视频卡片：显示在**标题下方**
- 播放页 UP 区：显示在 **UP 面板最左侧内侧**，并自动限宽，绝不遮挡头像
- 用户空间页：显示在**昵称右侧空白区**
- 超过 3 个折叠为 `+N`，悬停查看全部
- 无标记时显示 `＋标`，有标记时显示 `✎`，点击打开标记面板

标记默认**完全清晰常显**（不再半透明看不清）；若嫌打扰，可用菜单或管理面板切换为「半透明」模式（悬停恢复清晰）。任意位置都可整体微调偏移：菜单「位置微调」输入 `水平,垂直`（如 `-20,0`），「重置位置偏移」归零。

### 其他

- **隐身模式**：菜单命令或 `Alt+Shift+M` 一键隐藏整个浮层（照常记录，只是不显示）
- **性能**：仅渲染视口内的标记，滚动/缩放用 rAF 节流重算，节点扫描防抖 500ms，浮层上限 400 个
- **管理面板**：按昵称 / UID / 标记搜索，批量查看与删除
- **导出 / 导入 JSON**：换电脑、清缓存前记得备份
- 数据双写（油猴存储 + localStorage 镜像），降低丢失风险
- 递归穿透 Shadow DOM，兼容新版 Web Component 评论区与视频卡片

## 安装

**方式一：GreasyFork（推荐，可自动更新）**

→ https://greasyfork.org/zh-CN/scripts/599393

**方式二：从本仓库安装**

1. 安装油猴扩展：[Tampermonkey](https://www.tampermonkey.net/) / [Violentmonkey](https://violentmonkey.github.io/)
2. 打开 [ReplicantTag.user.js 原始文件](https://raw.githubusercontent.com/saiyajiang/ReplicantTag/main/ReplicantTag.user.js)，点击「安装」（或把文件内容粘贴进油猴新建脚本）
3. 打开任意 B 站页面即可生效

脚本头部为 GreasyFork 兼容格式，可直接在 GreasyFork 提交更新。

## 使用

1. 在评论区用户名、视频卡片 UP 名、播放页 UP 头像旁，找到 `＋标` 小按钮，点击打开标记面板
2. 面板会显示**当前上下文**（视频标题/BV/时间，或评论内容），确认无误后输入标记
3. 点击「添加」或回车；可一次输入多个标记
4. 标记会立即显示在页面上，下次打开同一页面自动带出
5. 油猴菜单 → 「打开标记管理面板」查看全部、导出备份、切换隐身模式

快捷键：`Alt+Shift+M` 切换隐身模式，`Esc` 关闭面板。

## 数据隐私

- 全部数据保存在本地浏览器（油猴存储 + localStorage），**不发送任何网络请求**
- 卸载脚本不会自动清理数据；如需彻底清除，请在管理面板「清空全部」后卸载
- 导出的 JSON 包含昵称、UID 与你写的标记，请自行妥善保管

## 已知限制

- B 站评论区改版频繁，若某天标记框未出现，通常是 `bili-comment` 内部结构调整，微调选择器即可，已有数据不受影响
- 浮层用 `getBoundingClientRect` 定位，页面发生复杂动画时标记可能有短暂跟随延迟；可用菜单「立即重新定位标记」手动校正
- 留痕只在你**打标记的那一刻**抓取上下文；事后页面内容变化不会回写
